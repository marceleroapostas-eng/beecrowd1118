# Beecrowd 1118 - Várias Notas Com Validação

## Descrição
Programa desenvolvido em Java para ler duas notas válidas de um aluno, calcular a média semestral e permitir a realização de novos cálculos.

## Linguagem
Java

## Entrada
O programa recebe valores reais correspondentes às notas do aluno, que devem estar no intervalo de 0 a 10. Após calcular a média, recebe uma opção para realizar um novo cálculo ou encerrar o programa.

## Saída
Imprime "nota invalida" para cada nota fora do intervalo permitido, a média com duas casas decimais e a mensagem "novo calculo (1-sim 2-nao)" para perguntar se deseja repetir o cálculo.
